## 📌 Overview
Lpage is a lightweight, fast, and user‑friendly landing page designed for a noodle restaurant.
It focuses on clarity, accessibility, and conversion, allowing visitors to quickly access essential information and place online orders via click‑and‑collect.

This repository includes:
- Full functional specification (cahier des charges)
- Wireframes
- User stories
- UML model
- Developer‑ready folder structure
- Documentation principles

---

## 🧩 User Needs (Functional Specification)
The client requires a simple landing page with three core objectives:

1. Allow customers to place online orders (click‑and‑collect).
2. Provide essential information: address, opening hours, phone numbers.
3. Display the menu clearly and visually.
